# 🏀 Basketball Scorer

A simple basketball scoring application that helps track live match scores, fouls, quarters, player points, and game statistics in real time.

## Features

- ✅ Live score tracking
- ✅ Team score updates
- ✅ Quarter timer support
- ✅ Player statistics
- ✅ Foul tracking
- ✅ Match history
- ✅ Reset game option

## Tech Stack

- Frontend: HTML, CSS, JavaScript / React
- Backend: Node.js / Firebase (if used)
- Database: MongoDB / Firebase / MySQL

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/basketball-scorer.git
```

2. Go to the project folder:

```bash
cd basketball-scorer
```

3. Install dependencies:

```bash
npm install
```

4. Start the project:

```bash
npm start
```

## Usage

1. Open the app.
2. Add team names.
3. Start the game.
4. Update scores during gameplay.
5. Track player stats and fouls.
